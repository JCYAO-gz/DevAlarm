# DevAlarm 程序员闹钟

常驻桌面的圆形倒计时闹钟。程序员长期坐着办公，损伤腰部，需要定时提醒 坐-站立-走动
蓝色科技风圆环随剩余时间缩短，中央显示当前事件与总时长；到点后整个圆环左右摇晃、向外发光并循环响铃，点击圆环即可结束提醒并进入下一事件。

## 使用

1. 双击 `DevAlarm.exe` 启动，圆环默认出现在主屏幕底部居中。
2. 圆内分钟数下方的按钮用于**开始 / 暂停**计时：暂停时显示 ▶ 与“已暂停”，时间冻结；再次点击继续。
3. 事件名左右两侧的 ‹ › 箭头可直接**切换上一个 / 下一个事件**，切换后从该事件开头重新计时，暂停状态保持不变。
4. 圆内空白处按住左键拖动窗口；拖动**左下角或右下角的手柄**可等比缩放。
5. 倒计时结束后提醒会持续 10 秒（可修改），鼠标点击圆环立即结束提醒；不点击则等到提醒结束自动进入下一事件。
6. 右键圆环可打开菜单：

   | 菜单项                     | 说明                                   |
   | -------------------------- | -------------------------------------- |
   | 设置…                      | 编辑循环事件、提醒时长、皮肤，查看关于 |
   | 关于 DevAlarm V1.0 · JCYAO | 显示版本与作者                         |
   | 退出                       | 关闭程序                               |

## 设置

设置窗口分三页：

- **事件**：按顺序循环的多个事件。每个事件可设置名称（最多 12 字）、时长（分钟，支持 `1.5` 这样的小数）和提醒文案（最多 24 字，留空显示“时间到了！”）。可新增、删除、上下排序；右下角显示一轮总时长。提醒时长全局共用，默认 10 秒，可设为 1–120 秒，也可试听铃声。设置窗口可拖动窗口边缘调整大小。
- **皮肤**：目前只有“科技 HUD”。主题通过注册表扩展，后续新增皮肤会自动出现在这里。
- **关于**：应用版本、作者与配置文件的存放位置。

修改会在点击“保存”后生效并自动写入配置文件；点击“取消”不会改动当前运行状态。

## 配置文件

配置保存在 `%APPDATA%\DevAlarm\config.json`，程序会自动创建。文件损坏或字段异常时会回退到默认配置，不会导致启动失败。

默认事件：

| 事件 | 时长   | 提醒文案   |
| ---- | ------ | ---------- |
| 喝水 | 1 分钟 | 时间到了！ |
| 站立 | 2 分钟 | 时间到了！ |
| 坐   | 3 分钟 | 时间到了！ |

倒计时圆环从顶部起点开始，随剩余时间减少**逆时针缩短**。

删除配置文件或删除其中的 `events` 可恢复默认。若 `events` 仍是旧版默认值（「坐 40 分钟 / 站 20 分钟 / 走动 3 分钟」且未做过任何修改），程序会在启动时自动升级为上面的新默认，并保留窗口位置、缩放、提醒时长与主题；自行修改过的事件不会被覆盖。

## 系统要求

- Windows 10 / 11（64 位）
- 运行 exe 无需安装 Python

## 开发者

```bash
pip install -r requirements.txt

python main.py                 # 源码运行
python -m unittest discover -s tests   # 运行测试
python tools/preview.py        # 生成渲染预览图到 preview/
python tools/make_icon.py      # 重新生成图标
python tools/make_sound.py     # 重新生成铃声

pip install pyinstaller
python tools/build_exe.py      # 打包 dist/DevAlarm-V1.0-win64.exe
```

### 一键打包发布版

双击项目根目录的 **`build.bat`** 即可（首次运行会自动安装 PyInstaller）：它会先跑全部单元测试，通过后再调用 `tools/build_exe.py` 打包。

- 版本号只在 `devalarm/__init__.py` 的 `__version__` 里维护，产物名、exe 文件属性、关于页都跟着它走；
- 产物为 `dist/DevAlarm-V<版本>-win64.exe`，右键 → 属性 → 详细信息 可看到 ProductVersion / FileVersion；
- 命令行可用 `build.bat`，加 `nopause` 参数可在 CI 中免暂停。

注意：已开启的 DevAlarm 进程会占用同名 exe，打包前请先退出。`build.bat` 需保持 Windows 的 CRLF 换行。

技术栈：Python 3.13 + tkinter（仅作对话框宿主）+ Pillow + ctypes Win32 分层窗口，无其他运行时依赖。
